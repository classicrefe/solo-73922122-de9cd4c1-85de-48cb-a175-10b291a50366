# 水厂支管流量入仓前核查

数据质量员每日收到支管流量计 CSV 后，在入仓前用本网页检验：仪表给出的各管段流量
上下界，能否同时满足管网守恒（内部节点流入量 = 流出量，每段读数落在自身闭区间内）。

- **可行**：页面给出一组逐段整数读数与进水点总供水量，供人工复核；
- **无可行分配**：标明「该批待复核」；
- **区间非法 / 拓扑不合法 / CSV 格式问题**：报「输入错误」并指出具体行号与原因。

## 启动（Docker Compose）

```bash
docker compose up --build
```

浏览器打开 <http://localhost:8000>，上传 CSV（或直接粘贴文本），填写进水点、
出水点，点击「核查可行性」。页面提供示例 CSV 下载。

## CSV 格式

每行一条管段：`管段编号,起点,终点,流量下限,流量上限`

- 首行可带表头，中英文列名均可（如 `id,from,to,lower,upper`）；无表头时按上述顺序解析；
- 上下界为非负整数，且下限 ≤ 上限；
- 节点 2～8 个，管段 ≤ 12 条；
- 管段须组成从进水点到出水点的有向无环网络，且所有节点都在进水点到出水点的通路上。

示例（`sample.csv`）：

```csv
管段编号,起点,终点,流量下限,流量上限
P1,S,A,0,10
P2,S,B,2,5
P3,A,B,0,3
P4,A,T,0,10
P5,B,T,0,6
```

## 判定方法（FastAPI + NetworkX）

采用「下界消去 + 最大流」经典归约（`app/solver.py`）：

1. 每条管段 `u→v`（区间 `[lo, hi]`）容量改为 `hi - lo`，下界 `lo` 转化为两端节点的供需量；
2. 管段经中间节点拆分，天然支持平行管段；
3. 加超级源/超级汇承接各节点供需，并加「出水点→进水点」回流边化为循环流；
4. 用 NetworkX 求最大流：超级源发出的边全部满流 ⟺ 原问题可行；
   管段读数 = `lo +` 拆分边上的流量。容量全为整数，最大流解必为整数。

## 本地测试（无需安装依赖）

```bash
python3 -I tests/run_tests.py
```

测试通过 `tests/stub/` 下的 networkx 最小替身加载求解器（Docker 镜像内使用真正的
networkx），覆盖可行/不可行/输入错误三类共 22 项用例。

## 目录结构

```

  main.py              FastAPI 入口：上传/粘贴 CSV、渲染结果
  solver.py            解析、校验与可行性求解（NetworkX 最大流）
  templates/index.html 单页表单与结果展示
Dockerfile
docker-compose.yml
requirements.txt
sample.csv             示例数据
tests/                 本地测试（不进镜像）
```
